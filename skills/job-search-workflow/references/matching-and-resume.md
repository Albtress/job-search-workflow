# 匹配与事实

1. 事实优先级：用户最新确认 → 有来源的本地素材 → 原始文档。旧简历和模型改写不是新事实。只有usable=true的素材可用于评估。
2. 逐条保留JD要求、证据及met/unknown/unmet。必备与优先分开；相关专业不等于所有学科代码。未确认的设备、实验、英语、商业客户或生产规范经验不能补写。
3. 科研方法、分析、表达和协作不自动成为企业任职、GMP/QC、专业维修或工艺放大。课程不是独立设备操作，组学解释不是全流程生信开发。
4. 数字保留单位、条件、对照、约数和本人贡献。预期论文和计划实验不算成果；作者角色不等于文章已发表。
5. 匹配至少两项有素材ID的核心任务。跨行业可保留职责相近且差距可培养的岗位，不把“愿意学”当核心证据。相对机会不是录用概率。
6. 工资门槛和税前/税后、固定/综合口径按用户填写。公告区间不等于录用工资；未知工资与招聘身份投递前说明，可经具体授权询问。
7. 简历选材随岗位变化，沿用用户模板，核验哈希、页数、文本与实际渲染。没有渲染条件时说明限制，不伪填visual_reviewed。
8. 个人资料和投递记录留在本地数据目录，不进入GitHub源码或测试夹具。
