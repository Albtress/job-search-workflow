# 流程检查与改进

| 已发现的问题 | 公开首版处理 |
|---|---|
| 姓名、路径与邮箱写死，无法复用 | 配置与运行数据外置，只按白名单复制源码 |
| 文档混有未接通、已实测等历史状态 | 入口区分本地、邮箱、官网实验与定时能力 |
| 待确认岗位依赖一次性脚本 | 正式allow-review绑定本次评估，保留unknown；明确不符、过期、变更、超额度仍阻止 |
| SMTP成功但已发送没有邮件 | 接受后追加副本并读回核验，副本失败不重发申请 |
| QQ按Message-ID搜索漏结果 | 读取实际邮件头查重，读取不完整就停止追加 |
| 同公司相近岗位可能重复发信 | 同公司同邮箱当日阻止重复，相关意向合并表达 |
| 只有技术回执，不方便用户记账 | 投递快照保留薪资地点来源，自动CSV并要求聊天表格 |
| 程序检查被误当事实和视觉认证 | 事实复核与实际渲染单独要求，manifest只是检查记录 |

保留限制：凭据仅Windows DPAPI；官网无通用ATS保证；退信/邀约未自动分类；无内置调度。本版不增加云端档案、外部模型评分服务或复杂后台。
